# git-practice

오픈소스 소프트웨어 수업에서 Git과 GitHub의 기본 사용법을 연습하는 저장소입니다.
로컬에서 파일을 만들고, 작업 단위로 커밋한 뒤 GitHub 원격 저장소에 Push하는 과정을 실습합니다.

## 파일 구성

- `README.md`: 저장소 목적과 파일 안내
- `.gitignore`: Git 추적에서 제외할 파일 규칙
- `git-commands.md`: 실습에 사용하는 기본 명령어
- `practice-log.md`: 로컬 작업 과정과 원격 연결 방법
- `checklist.md`: 제출 전 확인할 요구사항

## 실습 범위

별도 프로그램이나 추가 패키지 없이 Markdown 문서로 버전 관리를 연습합니다.
파일을 추가하는 작업을 다섯 개의 커밋으로 나누어 기록합니다.
